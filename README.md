# Vocabulator

This is the landing page for Vocabulator. This project is developed through the hack club ysws "terra"

**Live Demo:** [vocabulator Website](https://vocabulator-page.vercel.app)

## Features

It's a landing page for my websiet vocabulator (another terra project) you find infos. The Features tab is build like the vocab cards in Vocabulator.

## Tech Stack

- Next.JS with Tailwind CSS and TypeScript and motion Framework.

## Running it locally

To run this project locally you must clone the repo and have nodejs installed. Then you can run following commands. You need to create an .env.local file see .env.example for an example.

```bash
git clone https://github.com/DundreDE/vocabulator-page.git
cd vocabulator
npm install
npm run dev
```

Or to test the production build instead:

```bash
git clone https://github.com/DundreDE/vocabulator-page.git
cd vocabulator
npm install
npm run build
npm run start
```
